# Horae brand marks

Source vector files for the Horae mark and lockups. They are not part of the
served app bundle.

The mark is a sun on a horizon inside a rounded square. A lockup is the mark
followed by the "Horae" wordmark (Newsreader).

| File | What it is |
|---|---|
| `horae-icon.svg` | Mark with rays, full colour (pine square, amber sun) |
| `horae-icon-norays.svg` | Mark without rays, full colour |
| `horae-icon-light.svg` | Mark with rays, for light backgrounds (same colours as `horae-icon.svg`) |
| `horae-icon-light-norays.svg` | Mark without rays, for light backgrounds |
| `horae-icon-pine.svg` | Mark with rays, reversed on dark pine |
| `horae-icon-pine-norays.svg` | Mark without rays, reversed on dark pine |
| `horae-lockup-dark.svg` | Lockup for dark backgrounds (cream wordmark) |
| `horae-lockup-light.svg` | Lockup for light backgrounds (ink wordmark) |
| `horae-lockup-pine.svg` | Lockup reversed on dark pine |

`site/index.html` and `site/favicon.svg` inline their own copies of the mark,
so changes here do not reach them automatically.
